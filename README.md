# 🚀 Vaibhav Badhe — Senior Flutter Developer Portfolio

An ultra-modern, high-performance, and responsive developer portfolio built with **React**, **Vite**, **Tailwind CSS**, **Lucide Icons**, and **Framer Motion**.

---

## 🌟 Key Features

- **⚡ Sleek Dark Theme:** Premium developer aesthetics with glassmorphic cards, custom radial glows, and responsive layout.
- **📱 Simulated Flutter Phone Mockup:** Interactive switcher in the Hero section showcasing real production apps (BAAP CRM, Simplify VMS, Goyant).
- **📦 Open Source pub.dev Showcase:** Dedicated spotlight for `toast_service` package with 1-click command copy and interactive in-browser toast simulations.
- **🏆 10+ Production Apps:** Filterable showcase across Enterprise, CRM, Education, Travel, and Fintech with deep-dive modal windows.
- **📄 Interactive Resume Viewer & Download:** Embedded PDF viewer with celebratory confetti animations upon download.
- **🎯 Architecture & Clean Code:** Dedicated section on Clean Architecture (Domain, Data, Presentation) and production resilience.
- **💬 Direct Contact & WhatsApp:** Working message form, direct mailto fallback, and instant WhatsApp chat link.

## 🛠️ Quick Start

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized, production-ready bundle in the `dist/` directory.

### 3. Deploy to Vercel / Netlify / GitHub Pages
- **Vercel:** Just import this folder into [Vercel](https://vercel.com) and deploy in 1-click.
- **Netlify:** Drag and drop the `dist/` folder or connect via GitHub.
- **GitHub Pages:** Push to GitHub and deploy with GitHub Actions.
